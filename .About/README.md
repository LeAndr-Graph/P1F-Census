# Perfect 1-factorization of K18 and K20

Complete, isomorph-free catalogues of perfect 1-factorizations (P1Fs) of complete graphs with
non-trivial automorphism group, with the engine and run scripts that reproduce them:

- K18, |Aut| > 1: 10,710 classes
- K20, |Aut| > 2: 149,836 classes

For more information see the [main README](../README.md).
