Notation: [`../ReadMe.md`](../ReadMe.md).

## Restart

`K16Aut3-All` takes seconds and `K16Aut2` about 7 minutes (it stops at its harvest target),
so an interrupted run is simply run again: delete its log and result file and start `run.bat`.
